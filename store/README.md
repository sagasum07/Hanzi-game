## 1. 출시용 서명 키 만들기 (처음 한 번만)

플레이에 올리는 앱은 서명 키로 서명해야 합니다. 아래 명령을 터미널에서 실행하면 비밀번호와 이름 등을 묻습니다.

```bash
mkdir -p ~/AndroidKeys
"/Applications/Android Studio.app/Contents/jbr/Contents/Home/bin/keytool" -genkeypair -v -keystore ~/AndroidKeys/zhongwenxuexi-upload.jks -alias upload -keyalg RSA -keysize 2048 -validity 10000
```

그다음 `android/keystore.properties.example`을 `android/keystore.properties`로 복사하고, 키 파일 경로와 비밀번호를 채웁니다.

> ⚠️ 키 파일(`.jks`)과 비밀번호는 **절대 잃어버리면 안 됩니다.** 앱 업데이트를 올릴 때마다 필요합니다.
> 클라우드 드라이브나 USB 등 다른 곳에도 백업해 두세요. (git에는 올라가지 않도록 설정되어 있습니다)
> Play 앱 서명을 사용하므로, 만약 잃어버려도 Play Console 고객센터에 요청해 키를 재설정할 수는 있지만 며칠이 걸립니다.

## 2. 앱 번들(.aab) 만들기

```bash
npm run android:bundle
```

결과물: `android/app/build/outputs/bundle/release/app-release.aab`

새 버전을 올릴 때는 `android/app/build.gradle`의 `versionCode`를 1씩 올리고(`versionName`도 1.0.1 등으로) 다시 만듭니다.

## 3. Play Console 진행 순서

1. **앱 만들기**: 앱 이름 `中文学习`, 기본 언어 한국어, 앱(게임 아님), 무료
2. **비공개 테스트 트랙**에 `.aab` 업로드 (Play 앱 서명 사용 = 기본값 그대로)
3. 테스터 이메일 등록 → 테스트 참여 링크를 테스터에게 공유
   - 새 개인 개발자 계정은 **테스터 12명 이상이 14일 연속** 참여해야 프로덕션(정식 출시)을 신청할 수 있습니다.
4. **Firebase에 플레이 서명 키 SHA-1 추가** (스토어에서 받은 앱의 구글 로그인에 필요)
   - Play Console → 테스트 및 출시 → 설정 → **앱 무결성** → 앱 서명 키 인증서의 **SHA-1** 복사
   - Firebase 콘솔 → 프로젝트 설정 → 中文学习 Android 앱 → **디지털 지문 추가**
   - 같은 화면의 **업로드 키 인증서 SHA-1**도 함께 추가해 두면 좋습니다.
5. 아래 스토어 등록정보·앱 콘텐츠 항목 입력
6. 14일 테스트 후 프로덕션 출시 신청
